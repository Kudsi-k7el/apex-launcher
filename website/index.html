Features

Built to actually launch games

Not a shop front. Apex finds what is already on your PC, keeps it tidy, and gets you into the game in one click.

One library, every store

FAQ

Good to know

Is Apex free?

Yes. Apex Launcher is free and open source under the MIT licence.

Does it download games I do not own?

No. Apex only ever offers a download for a title it can verify you own — a Steam licence, an Epic manifest, or files already on your disk. Everything else links out to the store that sells it.

Do I need an account?

Yes. Apex Launcher asks you to sign in the first time you open it, and it will not launch, install or download anything until you do. The account is what carries your profile, achievements and screenshots between PCs, and it is stored on the server you point Apex at — run one yourself with npm run serve, or host it anywhere. No telemetry is sent anywhere, and nothing is sent to us.

Will it fight with Steam or Epic?

No. Apex reads their metadata to know what is installed, and launches titles through the store that owns the licence rather than replacing it.

How do I uninstall it?

Windows Settings → Apps, exactly like anything else. Your library state lives in a single JSON file you can delete with it.
